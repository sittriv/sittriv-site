# SITTRIV - SERVICIOS INTEGRALES TECNOLOGICOS

Sitio estático responsive listo para publicar en **GitHub Pages**.

## Estructura
- `index.html`
- `styles/main.css`
- `js/main.js`
- `img/` (placeholders)
- `assets/favicon.svg`

## Personalización rápida
- Cambia el color principal en `styles/main.css` → `--primary` (actual: #65CB63).
- Edita textos en `index.html`.
- Reemplaza imágenes en `/img`.

## Formulario (Formspree)
1. Ve a https://formspree.io/ y crea un formulario.
2. Copia el ID como `https://formspree.io/f/XXXXXXX`.
3. Sustituye la acción del formulario en `index.html`.

## Publicar en GitHub Pages
1. Crea un repositorio en GitHub (p.ej. `sittriv-site`).
2. Sube estos archivos a la rama `main`.
3. En **Settings → Pages**, Source: `Deploy from a branch` → Branch: `main` (root).
4. Espera 1–2 minutos. Tu web quedará en `https://TU_USUARIO.github.io/sittriv-site/`.
